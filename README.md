## ◈ О проекте

**Digital Harassment KZ** — проект на Python для сбора, обработки и анализа новостных публикаций, связанных с цифровым преследованием, онлайн-шантажом, кибербуллингом, интернет-угрозами и цифровым мошенничеством в Казахстане.

Цель проекта — исследовать освещение проблем цифровой безопасности в СМИ с помощью обработки данных и визуальной аналитики.

## ◈ Основные возможности

| Модуль | Описание |
|---|---|
| Сбор данных | Получение публикаций через Google News RSS |
| Обработка | Очистка данных и удаление дубликатов |
| Классификация | Предварительное распределение публикаций по темам |
| Аналитика | Сравнение категорий и источников |
| Визуализация | Графики и интерактивные фильтры |
| Экспорт | Работа с данными в формате CSV |

## ◈ Технологии

`Python` `Pandas` `Requests` `BeautifulSoup` `Feedparser` `Trafilatura` `Plotly` `Gradio` `Google Colab`

## ◈ Запуск проекта

1. Открой `Digital_Harassment_KZ.ipynb` в Google Colab.
2. Выполни ячейки последовательно сверху вниз.
3. Дождись завершения сбора и обработки публикаций.
4. Изучи графики и результаты классификации.
5. При необходимости скачай обработанный датасет в CSV.

## ◈ Ограничения и ответственное использование

Классификация основана на ключевых словах и может содержать ошибки. Результаты требуют ручной проверки и не должны рассматриваться как окончательная оценка каждого случая.

Датасет отражает освещение темы в СМИ, а не фактическое количество случаев цифрового преследования в Казахстане.

При распространении данных необходимо учитывать авторские права, условия использования источников и требования к защите персональных данных.
