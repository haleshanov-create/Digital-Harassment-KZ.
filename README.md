## ◈ О проекте

**Digital Harassment KZ** — исследовательский проект на Python для сбора, обработки и анализа новостных публикаций, связанных с цифровым преследованием, онлайн-шантажом, кибербуллингом, интернет-угрозами и цифровым мошенничеством в Казахстане.

Цель проекта — изучить, как казахстанские СМИ освещают вопросы цифровой безопасности, используя обработку данных, тематическую классификацию и визуальную аналитику.

## ◈ Запуск проекта

1. Откройте `Digital_Harassment_KZ.ipynb` в Google Colab.
2. Выполняйте ячейки последовательно сверху вниз.
3. Дождитесь завершения сбора и обработки публикаций.
4. Изучите результаты классификации и графики.
5. При необходимости скачайте обработанный датасет в формате CSV.

Для самостоятельного размещения дашборда понадобятся `app.py`, `requirements.txt` и `Digital_Harassment_KZ_dataset.csv`. Их можно разместить на платформе, поддерживающей Gradio, например Hugging Face Spaces.

## ◈ Ограничения и ответственное использование

Классификация основана на ключевых словах и может содержать ошибки: публикации могут попадать в неподходящие категории, а релевантные материалы — не распознаваться. Для оценки качества необходима ручная проверка.

Датасет отражает публикации, найденные по заданным поисковым запросам, а не фактическое количество случаев цифрового преследования в Казахстане. Он не предназначен для установления виновности конкретных лиц.

При распространении данных необходимо учитывать авторские права, условия использования источников и требования к защите персональных данных. Полные тексты статей не следует публиковать без соответствующего разрешения.
