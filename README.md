# Digital Harassment KZ

**Анализ новостных публикаций о цифровом преследовании и шантаже в Казахстане**

## О проекте

Digital Harassment KZ — исследовательский проект на Python для сбора, обработки и анализа новостных публикаций, связанных с цифровым преследованием, кибербуллингом, шантажом и онлайн-мошенничеством в Казахстане.

## Возможности

- Сбор новостных публикаций через RSS-ленту Google News.
- Очистка и удаление дубликатов.
- Предварительная классификация публикаций по тематическим категориям.
- Анализ количества публикаций по категориям и источникам.
- Интерактивный дашборд с фильтрами.
- Экспорт результатов в CSV.

## Технологии

Python, Google Colab, Pandas, BeautifulSoup, Feedparser, Trafilatura, Plotly, Gradio.

## Запуск

1. Откройте ноутбук `Digital_Harassment_KZ_dataset (2).csv` в Google Colab.
2. Выполните ячейки последовательно сверху вниз.
3. Дождитесь сбора и обработки публикаций.
4. Откройте дашборд, чтобы изучить результаты.

## Ограничения

Классификация основана на ключевых словах и может ошибочно относить некоторые публикации к категориям. Результаты требуют дополнительной проверки. Проект анализирует публикации СМИ и не предназначен для установления виновности конкретных лиц.

## Конфиденциальность и источники

Проект ориентирован на анализ публичных новостных публикаций. При распространении датасета необходимо учитывать условия источников и авторские права. Полные тексты статей не следует публиковать без соответствующего разрешения.
